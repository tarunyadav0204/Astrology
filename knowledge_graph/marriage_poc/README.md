# AstroRoshni Marriage and Relationship knowledge graph

This module covers the existing Instant Chat routes for natal marriage promise,
marriage timing, married-life outlook, love and relationship outlook, separation
or reconciliation, spouse profile, repeated-conflict diagnosis, calculated
marriage remedies, love-versus-arranged pathways, remarriage, engagement versus
wedding timing, spouse meeting context, detailed spouse indications, affair
concerns, marriage Muhurat, and actual two-chart compatibility through the
dedicated Partnership Analysis flow.

It links to the canonical `MarriageRelationships` parent in the shared life-domain
ontology. Compatibility remains a dedicated Partnership Analysis operation and
is never inferred from one chart. Marriage Muhurat remains a dedicated electional
operation and is never substituted with natal event timing.

Validate and compile with:

```bash
python3 scripts/validate_marriage_ontology.py
```

The runtime preview and validation report are generated artifacts.
